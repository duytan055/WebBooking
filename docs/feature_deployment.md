# Chức năng Triển khai và Cài đặt

## Mô tả chức năng

Tạo tài liệu hướng dẫn cài đặt và triển khai dự án WebBooking trên môi trường local hoặc server.

## Công việc cần làm

1. Ghi rõ cách cài XAMPP/Apache/MySQL cho Windows.
2. Hướng dẫn đặt thư mục dự án vào `htdocs`.
3. Cấu hình `Connect/connecDB.php` với `servername`, `username`, `password`, `dbname`.
4. Thực thi script tạo database và các bảng.
5. Hướng dẫn chạy trang web trong trình duyệt.
6. Ghi chú về các quyền thư mục và file tài nguyên.

## Phân tích

- Nếu không có hướng dẫn triển khai, người khác khó thiết lập và chạy dự án.
- Đây là phần quan trọng để chuyển project từ phát triển sang thử nghiệm hoặc dùng thực tế.
- Nên ghi rõ các bước tạo database, restore dữ liệu, và cấu hình kết nối.

## Tiến độ hoàn thành

- [ ] Ghi rõ cách mở trang web trên localhost.
